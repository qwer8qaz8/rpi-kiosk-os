Built for Stability, Security & Everyday Control

A dual-mode architecture that keeps your dashboard fast while giving you full administrative power.

🖥️

macOS Admin Desktop

Switch smoothly into a desktop mode with a floating dock, real app icons, live menu bar, and windowed apps (Google Chrome, Preferences, Terminal Logs, and Camera Sensor) without stopping your display compositor.

🔐

Secret Sequence Unlock

High-security access barrier: press Ctrl + Alt + =, type Kiosk while listening in the corner, and unlock with your administrator password. Press Esc anytime to cancel.

📷

Camera Motion Detection

Turns connected USB webcams or CSI cameras into a room motion detector. Automatically publishes binary_sensor.kiosk_motion events to Home Assistant and wakes the display when you enter the room.

🌙

Automated Night Mode

Schedule display sleep during nighttime hours to eliminate room glare and save power. The screen stays completely dark and wakes automatically in the morning or upon room motion.

🏠

Home Assistant MQTT Ready

Full MQTT auto-discovery for 10+ smart entities: Screen Power, Display Brightness slider, CPU Temperature, RAM usage, Night Mode switch, and Camera snapshots.

🐧

Universal Linux Architecture

Not limited to Raspberry Pi. Runs on any x86_64 or ARM64 Linux system (Debian, Ubuntu, Fedora) using modern Wayland (Cage) or X11 display stacks.

Keyboard Shortcuts & Controls

Quick access shortcuts configured right out of the box.

Action Shortcut / Sequence Description
Enter Admin Mode Ctrl + Alt + = → type Kiosk → enter Password Activates corner listening badge, prompts for password, and opens the macOS Admin Desktop.
Exit Admin Mode Ctrl + Alt + = or click 🔒 Lock Instantly closes admin mode and locks display back to single-window fullscreen kiosk.
Cancel Listening Escape Dismisses the corner listening indicator and cancels the secret sequence.
Toggle Screen Power Ctrl + Alt + Shift + B Manually toggles screen power on or off without killing active applications.
System Reboot Ctrl + Alt + Shift + R Prompts and safely reboots the operating system.
