Built for Stability, Security & Everyday Control

A dual-mode architecture that keeps your dashboard fast while giving you full administrative power.

🖥️

Native macOS Desktop UI

Powered by native Wayland window management (labwc + waybar). Real Google Chrome browser windows, standalone Control Center, floating glass dock, live Apple menu bar, and native top-left traffic light window controls. Never trapped in a web tab.

🔐

Secret Sequence Unlock

Strict keystroke isolation: press Ctrl + Alt + =, type Kiosk while listening in the corner, and unlock with your administrator password. Home Assistant never intercepts key events.

👁️

Optical Camera Touch (Beta)

Turn any standard monitor or TV into an optical touchscreen! Overlays 4 high-contrast corner fiducials to calibrate screen boundaries and homography, tracking fingertip touches using an external webcam.

🖱️

Non-Touch & Touchscreen Modes

Tailored input hardware profiles: Standard display mode features smart auto-hiding cursor (fades after inactivity and awakens on motion), while Touchscreen mode delivers an immersive pointer-free touch experience.

🌙

Automated Night Mode & Motion

Schedule display sleep during nighttime hours with camera motion wake. Safe display blanking prevents compositor shutdown and integrates directly with Home Assistant MQTT.

🐧

Universal Linux Architecture

Works across Raspberry Pi OS, Debian, Ubuntu, and x86_64 PCs using modern Wayland and hardware-accelerated graphics.

Keyboard Shortcuts & Controls

Quick access shortcuts configured right out of the box.

Action Shortcut / Sequence Description
Enter Admin Mode Ctrl + Alt + = → type Kiosk → enter Password Activates corner listening badge, prompts for password, and opens the macOS Admin Desktop.
Exit Admin Mode Ctrl + Alt + = or click 🔒 Lock Instantly closes admin mode and locks display back to single-window fullscreen kiosk.
Cancel Listening Escape Dismisses the corner listening indicator and cancels the secret sequence.
Toggle Screen Power Ctrl + Alt + Shift + B Manually toggles screen power on or off without killing active applications.
System Reboot Ctrl + Alt + Shift + R Prompts and safely reboots the operating system.
